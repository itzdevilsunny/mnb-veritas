Installation

Command-Line Interface (CLI)

Execute live deterministic verification from terminal or CI/CD pipelines:

# Verify a claim with strict evidence gating
veritas verify "What is the capital outlay for National Green Hydrogen Mission for FY 2025-26?" --policy strict

# Verify and export a cryptographically signed compliance certificate
veritas verify "What is the policy repo rate for Q4 FY25?" --export-cert audit.pdf

# Check gateway circuits and provider availability
veritas health

# Verify SHA-256 tamper-evident audit ledger
veritas chain --json
Python SDK Quickstart

Programmatic integration using the async or sync client:

from veritas import VeritasClient, PolicyMode

async def main():
    async with VeritasClient(base_url="https://mnb-veritas.vercel.app") as client:
        result = await client.verify(
            query="What is the approved budgetary allocation for FY 2025-26?",
            policy=PolicyMode.STRICT,
        )
        print(f"Verdict: {result.verdict}")
        print(f"Answer:  {result.answer}")
        print(f"Audit:   {result.audit_id}")
